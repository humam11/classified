## Abstract

This diploma presents a comprehensive multilingual classified ads platform built using modern software engineering principles. The system employs ASP.NET Core 9.0 with Clean Architecture, utilizing a hybrid database approach combining PostgreSQL for relational data and MongoDB for document storage. The platform supports English and Russian languages with dynamic SEO-friendly routing, robust validation, and efficient image management.

**Keywords**: Clean Architecture, ASP.NET Core, PostgreSQL, MongoDB, Multilingual System, Classified Ads, LTREE, Discriminator Pattern
