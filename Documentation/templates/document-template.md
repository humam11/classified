## Template Guidelines

### Headings
- Use `#` for chapter titles (H1)
- Use `##` for main sections (H2)
- Use `###` for subsections (H3)
- Maximum depth: 3 levels

### Code Blocks
Always specify the language for syntax highlighting:
- C#: ```csharp
- SQL: ```sql
- JSON: ```json
- Bash: ```bash

### Lists
- Use `-` for unordered lists
- Use `1.` for ordered lists
- Indent with 2 spaces for nested items

### Emphasis
- **Bold** for important terms and concepts
- *Italic* for emphasis
- `Code` for inline code, file names, and technical terms

### Tables
```markdown
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Data 1   | Data 2   | Data 3   |
```

### Images and Diagrams
```markdown
![Diagram Title](../diagrams/images/diagram-name.png)
*Figure X.Y: Diagram description*
```

### Cross-References
- Link to other sections: `[Section Title](#section-title)`
- Link to requirements: `(Requirements: 1.1, 1.2)`
- Link to appendices: `(See Appendix A)`

### Transitions
End each major section with a transition statement that connects to the next section:
- "With the database schema established, we now examine..."
- "Having defined the domain layer, the next section explores..."
- "Now that we understand the routing system, we can examine..."
